# Скелет статьи: калиброванная генеративная ассимиляция SIC при одной реализации на условие

Рабочее название: *Conditional flow matching does not learn conditional uncertainty
when each condition is observed once: diagnosis and an out-of-fold remedy for
sea-ice data assimilation*.

Статус: 2026-09-18 (обновлено после native-прогонов), черновик структуры. Каждое утверждение помечено:
✅ — есть улика (файл), ⏳ — считается, ❌ — нужно получить.

## 1. Постановка

- OSSE-ассимиляция SIC: фон = поле того же дня прошлого года, наблюдения =
  точные значения M2M на реальной геометрии SRAL за дни d, d−1, d−2; анализ
  дня d. Протокол сопоставим с 3D-Var коллег (`compare_3dvar`, siconc-only).
- Модель: conditional flow matching (UNet 50M, concat-conditioning),
  10-членный ансамбль. ✅ (репозиторий, checkpoint run_20260607_184239)
- Цель: калиброванный ансамбль анализа; критерий — pooled-reliability по
  стратумам наблюдаемых признаков + proper scores + атомы + пространственная
  структура. Никаких стратификаций по исходу.

## 2. Утверждение 1: спред conditional FM в этом режиме — артефакт обобщения

- Теория: при одной реализации на условие эмпирический минимизатор любого
  strictly proper objective — δ в наблюдённой истине; CFM-скорость при точном
  условии — детерминированный транспорт. Спред на новых условиях задаётся
  сглаживанием по условиям; `spread/RMSE_OOS ≈ RMSE_in/RMSE_OOS` — однородный
  множитель. ✅ (Fable §2.1 + toy `collapse_toy_N512.log`)
- Эмпирика A: spread/RMSE .72–.76 во всех стратумах расстояния до трека и на
  всех масштабах (native .727 / 80×64 .720 / 20×16 .717). ✅
  (`audit_assimilation_track_distance_cpu.py`, `assimilation_spread_scale_effective_n.json`)
- Эмпирика B: кривые коллапса в логах обучения — чистая модель: mean RMSE
  .121 (эп. 7–10) → .149 (эп. 19), s/RMSE .68 → .43; 50 % безусловных шагов
  подавляют коллапс ценой −25 % skill. ✅ (`metrics.json` двух run'ов)
- Эмпирика C: доминирующая неопределённость — межгодовая мода (73 % variance
  крупномасштабной аномалии «истина − фон» объясняется (год, месяц); 72 % MSE
  на 20×16) с ~6 реализациями в train — почему у GenCast не так. ✅
- Решающий тест: in-sample (train-даты) vs OOS spread/RMSE, в двух протоколах. ✅ **Опровергает** generalization-gap для balanced_50m: siconc-only in-sample s/r .75 vs OOS .72; native in-sample RMSE .177 vs OOS .156 (виденные даты не легче). Коллапс запоминания доказан только для чистой модели (кривая legacy).
- Утверждение 1 переформулировано: (i) чистая CFM-модель коллапсирует к запоминанию (кривая); (ii) регуляризованная (50 % безусловных шагов) не коллапсирует, но её разброс — **константа обучающей выборки** (.135–.141 во всех клетках «год × протокол»), не функция условия: s/r .90 в 2022 native, .76 в 2019 native, .72 при OOD-протоколе siconc-only. ✅ (`claude_undertrained_or_overfit_ru.md` §3)
- Отрицательные результаты прошлой кампании как следствие: 15 семей
  post-hoc (C11–C40), 3 proper-score fine-tune. ✅ (CLAIM_LEDGER)

## 4. Метод: разделение структуры и величины неопределённости

- Принцип: генератор даёт точечный анализ и структуру; величина
  неопределённости и атомы — OOF-оценённый закон остатка в латенте с точным
  условием на треке дня d.
- Латент с атомами (вода → −γ·расстояние до кромки, cap → цензурирование);
  kriging-апдейт среднего по невязке obs − μ; закон остатка относительно
  kriged-среднего: гауссова копула × эмпирические маргиналы по ячейкам
  (расстояние до трека × бин kriged-среднего); двухмасштабное ядро.
  ✅ (`oof_dispersion_layer_v2.py`)
- Результат cross-fit dev-2022 (40 дат), siconc-only (v3): fair CRPS .0585 → .0417
  (−29 %, 40/40 дат), RMSE .190 → .158, s/r .93, нули .53 (truth .54).
  ✅ (`oof_layer_v3_full_condition_dev2022.json`)
- Результат в нормальных условиях (native-two-field, v3): CRPS .0415 → .0353
  (−15 %, CI95 [−.0096, −.0035], 33/40), RMSE .156 → .140, per-date rank-TV
  .157 → .085, нули .41 → .53, zero-atom Brier .069 → .039; cap .022 → .095
  (truth .060) — единственный оставшийся дефект надёжности. ✅
  (`oof_layer_v3_native2f_dev2022.json`, `fig_atom_reliability.png`)
- Что не помогло (все OOF): бин cap-вероятности генератора (v4, 0 %),
  ковариата невязки дня d (ρ с ошибкой слоя −.06), пер-датный масштаб
  разброса (оракульная верхняя граница −0.2 % CRPS). ✅ (analysis-doc §11)
- v5: OOF-порог декодирования cap по ячейкам (масса cap на training-фолдах =
  truth). ⏳
- Абляции: v0 (гаусс) / v1 (копула без kriged-mean) / фиксы кодека —
  показывают, что решает (а) согласованный латент наблюдений и (б) закон
  остатка относительно итогового среднего. ✅ (таблица итераций в analysis-doc)
- Операционная корректность: слой оценивается на прошлом периоде и
  применяется вперёд (2022 → 2023); будущие даты не используются. ✅ (описание)

## 5. Переобучение с нуля (arm A/B) — что даёт сама сеть

- Гипотезы H1–H3 (ранняя остановка по fair CRPS, dropout без безусловных
  шагов, модель ошибки наблюдения σ~U(0,.05)), H5 (field-dropout sithic под
  протокол siconc-only). Обучены (A@ep10, B@ep8, C@ep10); на training-метрике
  все лучше baseline (fair CRPS .032–.034 vs ~.045), на siconc-only A/B хуже.
  Оценка в нормальных условиях на тех же 40 датах ⏳ (очередь GPU).
- Ожидаемый вывод: лучший точечный анализ и структура; величина спреда всё
  равно из OOF-слоя. Абляция «сеть без слоя / сеть + слой / legacy + слой».

## 8. Ограничения

OSSE (модельная истина, точные obs); фон = прошлый год (унаследован от
протокола сравнения); один регион, одна модель; 40 dev-дат; калибровка —
в среднем по стратумам, не по датам; cap-масса слоя на 40 % выше truth;
кромка членов слоя пиксельная (ℓ₁ = 1.5 px).
