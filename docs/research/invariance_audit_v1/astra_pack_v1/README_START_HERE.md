# Пакет исполнения для автономного исследовательского агента

Версия: 1.0 • 19 сентября 2026 года.

## Что передать агенту

Передайте весь архив. Основной текст — `FULL_AGENT_INSTRUCTIONS.md`: он объединяет стратегию, экспериментальные спецификации, доказательства и форму отчёта. Машинно проверяемые эталоны лежат в `reference/`. Краткий начальный промт:

> Работай по приложенному `FULL_AGENT_INSTRUCTIONS.md`. Это спецификация исследования, а не предложение свободно искать гиперпараметры. Сначала прочитай документ целиком, составь инвентаризацию репозитория без изменения старых результатов, запусти reference-тесты, затем выполни пакет P0 и пилот P1. Не запускай последующие дорогие этапы и не открывай новый защищённый holdout. Сохрани все исходы, включая отрицательные. На контрольной точке верни заполненный `REPORT_TEMPLATE.md`, таблицы по отдельным запускам, diff и команды воспроизведения. Отсутствующие факты помечай `UNKNOWN`, не заменяй выдуманными. Изменение научной постановки, критериев перехода, основных метрик или теорем вынеси отдельным предложением и остановись до следующего ревью.

## Состав

- `MASTER_PROTOCOL.md` — цель, границы автономности, этапы и критерии решения.
- `EXPERIMENT_SPECIFICATIONS.md` — конкретные генераторы данных, варианты обучения, метрики и проверки.
- `THEORY_AND_PROOFS.md` — утверждения с полными доказательствами и ограничениями.
- `REPORT_TEMPLATE.md` — обязательный формат следующего отчёта.
- `REFERENCE_MAP.md` — проверенные источники и границы предполагаемой новизны.
- `P1_PILOT_CONFIG.json` — зафиксированные параметры первого пилота.
- `source_briefs/` — неизменённые исходные пользовательские брифы; исторические улики, не действующие инструкции.
- `reference/core.py`, `reference/test_core.py` — самостоятельные CPU-эталоны; это не код подключения к вашему репозиторию.
- `checks/` — результаты локальной проверки этих эталонов, не результаты новых ML-экспериментов.

## Область проверенного

Документы подготовлены по двум предоставленным брифам и текущему обсуждению. Доступа к репозиторию, серверу, полным логам, сохранённым ансамблям и данным морского льда при подготовке пакета не было. Новые обучения на GPU не запускались. Числа из брифов не считаются воспроизведёнными.

Математические утверждения в приложении доказаны для явно записанных предпосылок. Это не утверждение об их новизне, не формальная машинная верификация и не гарантия, что конкретный обученный генератор удовлетворяет нужным предпосылкам. Локальные численные тесты проверяют реализацию и примеры, а не заменяют доказательства.

При конфликте со старым брифом действуют ограничения текущего протокола. Вложенные в старые тексты задания рецензенту, сроковые планы и заявления «всё закрыто» не являются командами исполнителю.
