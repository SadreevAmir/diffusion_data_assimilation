Источник: `docs/research/audit_layer_sampling_law_cpu.py` (LAYER_MODULE=v19), результат

## Что общее у банков A и B, что независимо (по коду, `oof_dispersion_layer_v19.py`)

| ингредиент | общий / независимый | где в коде |
|---|---|---|
| обученные веса генератора, фон, треки d/d−1/d−2, истина даты | общие (фиксированные входы) | inputs |
| сырые члены генератора: A = члены 0–4, B = члены 5–9 одного прогона dopri5 | **условно независимы** при фиксированных входах: у каждого члена свой начальный шум и seed (`_seed_member`), никакой нормировки между членами в генераторе | `evaluate.generate_ensemble` |
| параметры слоя `params` (ячейковые квантили `Q`, ядра `ell/ell1`, `s_track`, таблица `fmix_tab`) | общие, но подобраны на *других* датах (cross-fit 5×8, purge ±1) — фиксированные параметры, не случайность процедуры | `L.fit(train)` |
| среднее сырого ансамбля → маска ядра/кромки → `mu` → kriging-апдейт `mu2` и выбор `a0` по LOO невязок дня d | **независимо по банкам**: `L.prepare(cA)` пересчитывает `mu` по 5 членам банка; `kriged_mean` работает от `c["mu"]` банка | `prepare`, `kriged_mean` |
| стандартизованные аномалии `anom` (Σ_k ã_k = 0 внутри банка) | независимо по банкам (внутри банка члены зависимы — поэтому и нужен cross-score) | `prepare` |
| стационарные поля `g` и внутридатная PIT по ячейкам (pooled по членам банка) | независимо по банкам (rng — один объект, но потоки не совпадают; PIT считается по членам *своего* банка) | `simulate` |
| таблица `F_MIX` (кэш `_mixed_score_cdf(M, λ)`) | общая, зависит только от M и λ (не от данных) | `simulate` |
| bootstrap-индексы | в cross-score не используются | — |

Вывод: A и B — **две условно независимые (при фиксированных входах и параметрах) реализации всей стохастической
постобработки для 5-членного сырого ансамбля**. Общих случайных промежуточных оценок (pilot mean, совместная нормировка,
совместная PIT) нет.

## Что именно оценивает каждое число (`means` из JSON, 40 дат)

| число | estimand | значение |
|---|---|---|
| `full_plain` .0372 | ordinary CRPS объявленного конечного 10-членного слоёного ансамбля (10 сырых членов) — корректно названный estimand конечного прогноза | .0372 |
| `full_fair` .0337 | U-формула для того же ансамбля — **оптимистична** при зависимых членах (T4.3); репортовать только с оговоркой | .0337 |
| `bankA_fair`/`bankB_fair` .0346/.0336 | U-формула для 5-членных банков — та же оговорка | |
| `cross_AB` **.0331** | несмещённая оценка CRPS закона *случайного члена* процедуры «слой поверх 5 сырых членов» (T7); **не** закон 10-членной процедуры | .0331 |
| `raw_fair` .0415 | fair CRPS 10 сырых членов — несмещён (члены условно iid) | .0415 |
| `raw_cross` .0413 | cross-score сырых банков — подтверждает несмещённость raw_fair (.0413 ≈ .0415) | .0413 |

Следствия для текста: (1) утверждение «cross-score исключает артефакт зависимости» заменить на «cross-score двух условно
независимых 5-членных запусков даёт .0331 для закона случайного члена 5-членной процедуры; ordinary CRPS 10-членного
конечного ансамбля — .0372; fair-оценка .0337 оптимистична и не является оценкой ни того, ни другого закона без оговорки»;
(2) выигрыш к сырому ансамблю по корректно названным объектам: ordinary 10-членный .0372 против raw fair/cross .0415/.0413
(−10 %); случайный член 5-членной процедуры .0331 против raw .0413 (−20 %); (3) end-to-end независимость «двух прогонов
CFM» не требуется для условной независимости банков — сырые члены условно iid по построению семплера; повтор всей
процедуры с новой генерацией CFM даст тот же estimand при тех же входах и не запланирован.
