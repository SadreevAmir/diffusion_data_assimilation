**[R13] Gruber & Buettner, «A Bias-Variance-Covariance Decomposition of Kernel Scores for Generative Models», ICML 2024
(PMLR 235; arXiv:2310.05833).** Объект: предсказательное распределение P̂, случайное относительно обучения (данные/seed).
Теорема 3.2: E S_k(P̂, Y) = −‖Q‖²_k + ‖E P̂ − Q‖²_k + Var_k(P̂), Var_k(P̂) = E‖P̂ − E P̂‖²_k (опр. 3.1, ур. 3). Для n
одинаково распределённых членов: Var_k(P̂^(n)) = Var/n + (n−1)/n·Cov (ур. 6); выигрыш усреднения = (n−1)/n·(Var − Cov)
(пример 3.4, ур. 8). Несмещённый оценщик Var_k **только по сгенерированным сэмплам** (ур. 9, §4.1: «внутрикластерная минус
межкластерная похожесть»). Kernel entropy для UQ, эксперименты на изображениях/аудио/тексте/QA.

**[R14] Krüger, «A Kernel Score Perspective on Forecast Disagreement and the Linear Pool», arXiv:2412.09430.** Kernel score
линейного пула = средний score компонент − среднее попарное расхождение (disagreement, MMD) компонент; расхождение
считается по прогнозам без исходов; условия оптимальности равных весов.
