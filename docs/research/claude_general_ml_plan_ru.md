# План general-ML статьи: «Когда условной генеративной модели можно верить как постериору»

Дата: 2026-09-18 (вечер). Статус: черновик плана + первые контролируемые
результаты. Автор: Claude. Все числа — из `docs/research/general_ml/`.

## 1. Тезис

Условная генеративная модель (flow matching / diffusion), обученная на
парах (условие, реализация), является **непараметрической оценкой условной
плотности с неявной полосой сглаживания по условию**. Она выдаёт правильное
условное распределение тогда и только тогда, когда у условия есть «соседи»
в обучающей выборке на масштабе, где p(y|x) ещё не меняется. Когда условие
идентифицирует обучающую реализацию (одна реализация на ключ и нет соседей),
эмпирический минимизатор любого strictly proper objective — δ в этой
реализации, разброс модели — артефакт полосы, сжимающийся с обучением.
Никакая замена loss/сэмплера этого не меняет. GenCast калиброван, потому что
условий 58k и p(y|x) гладка по ним; ассимиляция льда с фоном прошлого года —
нет, потому что ключ (фон) уникален и реализаций на него одна.

## 2. Контролируемые результаты (истина известна)

### 2.1 Плотность условий, а не число реализаций (`synth_realizations_per_condition.py`)
MLP-CFM, x ∈ [−1,1]², y ∈ R¹⁶, p(y|x) гауссова с известной σ(x).
- Бюджет N·k = 2048 фиксирован: k = 1 (N = 2048) → spread/σ .92–.94, ранги
  плоские — **калибровано при одной реализации на условие**, потому что
  условий плотно. k = 16 (N = 128) — то же .92–.95.
- N = 512 фиксировано: k = 1 → spread/σ .92 → .81 (20k шагов), rank-TV
  .06 → .15, OOS-RMSE .079 → .101 (переобучение); k = 16 → .95 стабильно.
Вывод: ось — **плотность соседей**, k важно только через неё.

### 2.2 Условие = зашумлённая частичная выборка цели («только треки»)
(`synth_noisy_partial_obs.py`, истинный постериор считается точно на сетке)
v1 (шум фиксирован на обучении): коллапс при любом σ_obs ∈ {0, .03, .1}
(spread/σ .17–.33, ранги U) — фиксированный шум входит в отпечаток.
v2 (шум пересэмплируется, но маска из 8 008 паттернов случайна): коллапс при
всех σ и RMSE вдвое хуже оптимума — условие слишком разрежено, чтобы
выучить даже среднее; не тест, а предупреждение о размерности условия.
**v3** (фиксированные 6 наблюдаемых координат — плотное 6-мерное условие,
шум пересэмплируется каждый шаг, `synth_noisy_partial_obs_v3.json`),
20k шагов, spread/σ_true (rank-TV; RMSE vs оптимум постериора):

| N | NN-расстояние | σ_obs = 0 | σ_obs = .1 | σ_obs = .3 |
|---|---|---|---|---|
| 512 | .19 | **.24** (TV .44; .325 vs .232) | .62 (.23) | **.96** (.07; .391 vs .371) |
| 2048 | .14 | .81 (.20) | .91 (.10) | .99 (.06; .355 vs .349) |
| 8192 | .11 | **1.00** (.12; .197 vs .177) | 1.00 (.05) | 1.00 (.06) |

Три вывода, все против известной истины: (1) при точных наблюдениях модель
коллапсирует, пока условий мало (N = 512), и **калибрована из коробки**,
когда их много (N = 8192) — плотность условий, не шум, первична;
(2) **шум на условии = полоса сглаживания**: калибровка появляется, когда
σ_obs превышает NN-расстояние между обучающими условиями (σ = .3 > .19 при
N = 512 → .96; σ = .1 < .14 при N = 2048 → .91), и тогда модель — почти точный
постериор *зашумлённой* задачи (ES .90 vs истинный .90); (3) цена — skill:
оптимальный RMSE растёт с σ (.23 → .37), т.е. шум калибрует, покупая
калибровку информацией. Ровно это и есть arm A/D/E на льде.
Следствие для высокой размерности условия (треки ~600 px, ~2 000 дат):
NN-расстояние велико, белый шум σ = .05 (arm D) далеко ниже → прогноз:
arm D коллапсирует; калибровать может только *крупномасштабный когерентный*
шум амплитуды межгодовой аномалии (~.2–.3), т.е. «фон как наблюдение с
ошибкой B», либо огрубление условия (двухстадийная схема).

### 2.3 У реального условия нет соседей (`audit_condition_neighbours_cpu.py`)
Для 40 dev-дат 2022: расстояние от фона (крупный масштаб 8×8, 2 170 обучающих
фонов 2015–2020) до ближайшего обучающего фона против RMS аномалии
«истина − фон», которую нужно предсказать. В ледовый сезон отношение
NN-расстояние / масштаб аномалии = .3–1.07, **медиана .47**; ближайший сосед
часто из другого месяца (03-05 → NN 2016-01-15). В синтетике v3 калибровка
требовала NN-расстояния заметно меньше масштаба вариации (N = 8192: ~.3 —
калибровано; N = 512: ~.6 — коллапс). Лёд сидит в режиме коллапса: у условия
нет соседей на нужном масштабе, а те, что «ближе масштаба аномалии», — это
соседние дни *того же* года (та же реализация) или другой сезон.

### 2.4 «Три закона» (по ревью §3, `synth_three_laws.{py,json}`)
На одних и тех же 96 держанных условиях: истинный постериор P* (сетка 161×161;
сходимость проверена против 81×81: разница средних .004), эмпирическая
аугментированная смесь P̂_{D,σ} (цель Теоремы 2, без обучения), точное
CFM-поле смеси через Euler-32 (ODE-ошибка), сеть Q_θ.

| N | σ | закон | spread/σ* | RMSE ср. vs P* | ES (P*: ref) | rank-TV | N_eff смеси |
|---|---|---|---|---|---|---|---|
| 512 | .1 | смесь / ODE(смесь) / **сеть** | .57 / .59 / **.61** | .289 / .284 / **.158** | 1.25 / 1.23 / **.79** (ref .55) | .63 / .63 / **.27** | 1.4 |
| 512 | .3 | смесь / ODE / сеть | .97 / .96 / .95 | .172 / .174 / .143 | 1.09 / 1.10 / .97 (ref .91) | .15 / .15 / .11 | 7.8 |
| 2048 | .1 | смесь / ODE / **сеть** | .58 / .59 / **.90** | .215 / .213 / **.106** | 1.13 / 1.12 / **.68** (ref .65) | .56 / .53 / **.10** | 1.8 |
| 2048 | .3 | смесь / ODE / сеть | .99 / .97 / 1.00 | .135 / .130 / .108 | 1.00 / 1.01 / .95 (ref .93) | .10 / .11 / .07 | 21 |

Выводы: (1) интегратор точен (ODE(смесь) ≈ смесь). (2) При σ = .3 цель
Теоремы 2 сама близка к истинному постериору, и сеть её воспроизводит —
режим «шум = полоса». (3) При σ = .1 цель почти точечная (N_eff 1.4–1.8),
но **сеть заметно лучше своей цели** (N = 2048: spread .90, rank-TV .10, ES
.68 при истинном .65) — это ряд 3 таблицы ревью: собственное неявное
сглаживание сети (по гладкости в x) добавляется к полосе σ. Т.е. критерий
σ ≳ d_NN относится к *цели обучения*; полная эффективная полоса =
σ ⊕ h_net, и h_net (зависящая от ёмкости и длительности обучения — это и
есть кривая коллапса) может спасать калибровку, когда σ мала, но без
гарантии. Формулировка для статьи: Теорема 2 даёт гарантированный
«пол»; выше него — индуктивное смещение, которое надо измерять, а не
предполагать.

## 3. Реальный кейс (лёд): причинные вмешательства на одной модели
| arm | условие | ожидание |
|---|---|---|
| legacy / balanced / A / C | фон + точные треки | коллапс или константный разброс (есть) |
| **D** (готово) | только треки, белый шум .05 | **нет коллапса**; полная оценка (dopri5, 10 чл., 40 дат): full RMSE .171 (с фоном .156), s/r .86; **у треков калибровано** (s/r 1.00, cov80 .82, RMSE .098 лучше модели с фоном .106) |
| **E** (готово) | только треки, реальная геометрия, когерентный SIC-зависимый шум (.05–.22) | нет коллапса, s/r .55–.59; у треков лучше D (.100 vs .120), в целом хуже (меньше информации в сэмпле, не сошлось) |
| F (план) | огрублённый фон (20×16) + треки | внутримесячная неопределённость выучиваема, межгодовая — нет |
| G (план) | двухстадийная: μ̂ по полному условию + генератор OOF-остатка по неидентифицирующим признакам | калибровка при skill μ̂ |

## 4. Метод, который остаётся в любом исходе
Post-hoc: генератор как регрессор + копула; OOF-маргиналы; ECC/GCA-смесь
(v13). Гарантии: маргиналы и обменяемость — по построению; совместная
структура — проверена многомерными score (ES −16 %, блочный CRPS −21…−34 %,
variogram хуже на 1–4 px → v15). Утверждения к доказательству:
(A) разброс сглаживателя = ширина смеси соседей; (B) копула смеси реальных
реализаций ≈ истинная копула в location-scale семействах — **подтверждено
синтетикой** (`synth_copula_check.json`: при коллапсе spread/σ .81 → .65
корреляционная структура членов остаётся на corr .94–.96 с истинной K);
(C) слой не резче информации ячеек. Формулировки — `claude_theory_notes_ru.md`.
