# Теоретические заметки к general-ML статье (черновик утверждений и набросков доказательств)

Дата: 2026-09-19. Статус: рабочие формулировки; каждое утверждение помечено
уровнем строгости: [станд.] — стандартный результат с ссылкой, [набросок] —
наше утверждение с планом доказательства, [эмп.] — проверено численно.

## Обозначения
Условие x ∈ X, цель y ∈ Y = R^m. Обучающая выборка {(x_i, y_i)}_{i=1}^N,
y_i ~ p(·|x_i). Модель Q_θ(·|x) — закон, порождаемый потоком с полем
v_θ(y_t, x, t), обученным CFM-objective
L(θ) = E_{i, t, y_0} ||v_θ(y_t, x_i, t) − (y_i − y_0)||².

## П0 [станд.] Population-limit
Если L минимизируется по всем измеримым v при N → ∞ (по совместному p(x,y)),
то Q_θ(·|x) = p(·|x) п.в. (Lipman et al. 2023; условная версия — Tong et al.
2023). — Ничего не говорит о конечном N по оси x.

## П1 [станд.] Эмпирический минимизатор при одной реализации на условие
Для любого strictly proper objective S и любого x_i, встречающегося в
выборке один раз, минимизатор эмпирического риска по неограниченному классу
законов в точке x_i есть δ_{y_i} (по определению strict properness:
E_{y~δ_{y_i}} S(Q, y) = S(Q, y_i) минимизируется единственно при Q = δ_{y_i}).
Для CFM: условная скорость (y_i − y_0)/(1) при точном условии даёт
детерминированный транспорт всего шума в y_i. — Следствие: замена
objective (CRPS, ES, NLL) минимизатора не меняет.

## П2 [набросок] Сглаживатель: разброс на новом условии
Модельная гипотеза: обученная сеть с конечной ёмкостью реализует
Q_θ(·|x) ≈ Σ_i w_h(x, x_i) δ_{y_i} с ядром w_h ширины h (эффективная
гладкость по x), h ↓ с числом шагов обучения (кривая коллапса).
Утверждение. Пусть p(·|x) = N(μ(x), Σ(x)) (или любое location-scale
семейство с копулой C), μ, Σ липшицевы по x. Тогда
  Cov[Q_θ(·|x)] = Σ_i w_i Σ(x_i) + Σ_i w_i (μ(x_i) − μ̄)(μ(x_i) − μ̄)ᵀ + O(1/N_h),
где N_h = Σ_i w_i / max w_i — эффективное число соседей. Первое слагаемое →
Σ(x) при h → 0; второе — «разброс истин соседей» O(L_μ² h²); третье —
дисперсия выборочного среднего по N_h точкам. При N_h → 1 (нет соседей)
Cov → 0: коллапс. При N_h → ∞ и h → 0 согласованно (Nh^d → ∞ в размерности
условия d) — состоятельность с обычной непараметрической скоростью.
План доказательства: прямое вычисление моментов смеси + стандартные
оценки для ядерных оценок (Nadaraya–Watson) условных моментов.
[эмп.] synth_realizations: N=512 → spread/σ .81 и падает, N=2048 → .93,
N=8192 (k=1) → 1.00; synth v3: калибровка при σ_obs > NN-расстояния.

## П3 [набросок] Шум на условии = полоса
Если при обучении условие подаётся как x_i + ε, ε ~ N(0, σ²I) свежее на
каждом шаге, то эмпирический минимизатор в точке x есть
Q(·|x) = Σ_i w_σ(x, x_i) δ_{y_i}, w_σ ∝ φ_σ(x − x_i) — ядерная оценка с
полосой σ, независимо от ёмкости сети (сеть не может различить, из какого
x_i пришло x + ε). Следствие: П2 с h = σ; калибровка достигается при
σ ≳ d_NN (медианное расстояние до соседа), ценой информации: цель
становится p(y | x + ε), чей оптимальный RMSE растёт с σ. В размерности d
d_NN ~ N^{−1/d}, поэтому нужный σ растёт с d — «шум как полоса» упирается в
проклятие размерности; выход — снижение d (огрубление условия).
[эмп.] synth v3, таблица в плане: σ=.3 > d_NN=.19 → spread/σ .96 при
N=512; RMSE_opt .23 → .37.

## П4 [набросок] Копула смеси реальных реализаций
Пусть p(·|x) — location-scale: y = μ(x) + S(x) z, z ~ F с копулой C, не
зависящей от x. Тогда копула смеси Σ_i w_i p(·|x_i) отличается от C на
O(sup_i ||S(x)⁻¹(μ(x_i) − μ(x))|| + ||S(x)⁻¹S(x_i) − I||) (по расстоянию
между копулами в sup-норме), т.е. при h → 0 копула сглаживателя → C, хотя
маргиналы (масштаб) искажены как в П2. Следствие: ECC-типа
перекалибровка маргиналов (OOF-квантили + копула модели) даёт совместный
закон с той же O(h)-ошибкой. План: оценка через разложение смеси
гауссовых копул / теорема о непрерывности копулы по параметрам сдвига-масштаба.
[эмп.] `synth_copula_check.json` (k = 1, MLP-CFM, истинная копула — K с
exp(−|i−j|/4)): при коллапсе маргиналов копула сохраняется.

| N | шаги | spread/σ | RMSE OOS | RMS-ошибка корреляций vs K | corr(C, K) |
|---|---|---|---|---|---|
| 256 | 4k → 20k | .81 → **.65** | .110 → .155 | .081 → .091 | .96 → .94 |
| 512 | 4k → 20k | .91 → .81 | .077 → .103 | .050 → .057 | .98 → .97 |
| 8192 | 4k → 20k | .96 → .93 | .060 → .056 | .036 → .027 | .99 → 1.00 |

Масштаб разброса падает на 20–35 %, структура зависимости — на уровне
шума оценки (ошибка корреляций .03–.09 при |K| до 1). Это и есть
эмпирическое содержание П4: сглаживатель искажает маргиналы, не копулу.

## П5 [станд.+набросок] OOF-слой: калибровка относительно σ-алгебры ячеек
Пусть c(x) — конечнозначная ячейка, r = y − μ̂(x), μ̂ обучен на других датах.
Эмпирический квантиль r в ячейке c по OOF-датам — состоятельная оценка
условного квантиля r | c при обмениваемости дат внутри ячейки; покрытие
OOF-квантильных интервалов валидно конечно-выборочно (split-conformal,
Vovk 2005; Lei et al. 2018) маргинально по ячейке. Полученный закон
auto-калиброван относительно σ(c) (Gneiting & Ranjan 2013) и является
единственным минимизатором ожидаемого proper score в классе законов,
измеримых относительно c. Резкость ограничена: E Var(y | c) ≥ E Var(y | x)
— слой не резче своей информации (П5c).
Обменяемость членов при смеси копул с λ > 0 — тривиально (независимая
компонента i.i.d. по членам, паттерны генератора обменяемы).

## П6 [набросок] Двухстадийная схема
Регрессор μ̂(x) по полному x; генератор остатка Q_φ(r | c(x)) по OOF-остаткам
с неидентифицирующим c. Для Q_φ применимы П0–П2 по оси c, где N_h велико
по построению (много дат на ячейку) ⇒ состоятельность по обычным правилам;
итоговый ансамбль μ̂ + r калиброван относительно σ(c) (П5) с выученной
копулой остатка. Два условия необходимы: (i) остатки OOF (иначе масштаб
остатка in-sample занижен — П1 через заднюю дверь); (ii) c не
идентифицирует дату (иначе П1). [эмп.] — план (arm G).

## Что доказывать в первую очередь
П2 и П3 (одна теорема о сглаживателе с полосой h/σ) и П4 (копула) — это
ядро; П5 — сборка известного; П6 — следствие П2+П5.
