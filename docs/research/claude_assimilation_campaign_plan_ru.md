**Причина переобучения (в отличие от GenCast):** доминирующая неопределённость —
межгодовая крупномасштабная мода с ~6 независимыми реализациями (лет) в train;
сеть её запоминает, а не выучивает как распределение. GenCast: мелкомасштабный
хаос, ~10⁵ условий. Плюс: длинное обучение (50–65k updates) без ранней остановки
по proper score; checkpoint брался `last`.

## 2. Гипотезы (falsifiable)

- **H1 (ранняя остановка):** чистая concat-модель на ранней эпохе (до роста
  val_loss) даёт лучший точечный анализ (RMSE ≤ .17 на dev-2022 протоколе
  `siconc-only`) при s/RMSE ≥ .6; дальнейшее обучение монотонно сжимает разброс.
- **H2 (регуляризация без потери skill):** conditioning-dropout 30 % (15 % без
  фона, 15 % без треков, 0 % безусловно) удерживает s/RMSE ≥ .8 на dev при
  RMSE не хуже legacy-эпохи-7 более чем на 5 %.
- **H3 (модель ошибки наблюдений):** гауссов шум σ∈[0, .05] на треках при
  обучении (а) убирает imprint (доля exact-zero on-track vs кольцо 2–3 px
  отличается ≤ .15 при truth = 0), (б) не ухудшает RMSE > 2 %, (в) даёт
  s/RMSE на треке дня d ≥ .8 при оценке с точными obs.
- **H4 (коллапс = generalization gap):** in-sample s/RMSE на 40 train-датах
  ≥ .9 при OOS .72 (тест AS-0.1).
- **H0 (структурный):** ни один вариант обучения не даёт exact-zero долю
  ≥ .5 при truth = 0 без явного кодека атомов → атомы требуют кодека/слоя.

## 3. Arm'ы обучения (ветка `claude/clean-retrain-v1`, коммит c8fc89e на сервере)

Общее: данные `m2m_2f_1y`, split `3dvar_main_200d` (train ≤2021, valid 2022),
`hour_mode=subset [23,5,11,17]` (540 updates/эпоха), UNet как у balanced_50m,
batch 16, lr 1e-4, EMA .999, 12 эпох (~6.5k updates), snapshot EMA каждой эпохи,
training-time dev-метрика: 12 дат 2022 × 8 членов Euler-16 (только для кривой).
Синтетические треки 50 %, empty 0.

| Arm | Отличие | Проверяет |
|---|---|---|
| A_clean | conditioning-dropout {bg .15, track .15, none 0, both .70}, obs точные | H1, H2 |
| B_obsnoise | A + шум наблюдений σ~U(0, .05) на train | H3 |

Стоимость: ~15 мин/эпоха обучения + ~3 мин метрика → ~3.5 ч на arm; параллельно
на двух GPU при свободных.

## 4. Оценка

1. Кривая коллапса по эпохам (из `metrics.json`): mean RMSE, s/RMSE, val_loss.
2. Выбор эпохи: минимум **fair CRPS** на 12 dev-датах (не val_loss, не RMSE);
   объявляется до полного прогона.
3. Полный протокол на выбранном snapshot'е: `validation_strict_full`, 40 дат
   2022-01-01…07-15 шаг 5, 10 членов, dopri5/25, `siconc-only`, ансамбли
   сохранены → `audit_assimilation_track_distance_cpu.py`,
   `audit_track_day_split_cpu.py`, imprint, панели членов.
4. Сравнение с baseline `balanced_50m` (learned full) и legacy-`ema_last` на тех
   же 40 датах.

Gate'ы для «кандидат лучше baseline»: fair CRPS ниже с CI по датам вне нуля;
RMSE среднего не хуже +2 %; s/RMSE в каждом стратуме расстояния ≥ .8; exact-zero
доля в 1–10 px ≥ .3 (baseline .14); imprint-разрыв ≤ .15; панели без
галлюцинаций в паке (ручная проверка). Ни один критерий не компенсирует другой.

## 5. Дальше (после arm'ов)

- H4-тест на train-датах для лучшего snapshot'а (2 GPU-ч).
- OOF-слой дисперсии (AS-1, латент с атомами + kriging на треке дня d) поверх
  лучшего точечного анализа; cross-fit 5×8 с purge на dev-2022; для теста —
  fit на всём 2022 → применение к 2023.
- Null-допуски gate'а (exchangeable warp) на train-датах.
- Финал: один прогон test-2023 замороженной конфигурации.
