## 0. Одна страница

**Задача.** Ансамбль анализа морского льда (концентрация SIC, 320×256 пикселей,
Арктика) из фона (поле той же даты годом раньше) и наблюдений на реальных
спутниковых треках (Sentinel-3 SRAL, ~700 пикселей в день, дни d, d−1, d−2).
OSSE: значения наблюдений — истина модели M2M на реальной геометрии треков.
Генератор — 50M UNet, conditional flow matching (CFM), обучение 2016–2021
(≈ 5 000 дат), dev — 40 дат 2022, test — 200 дней 2023 подряд (запечатан,
использован один раз). Одна реализация истины на каждую дату.

**Тезис.** Условная генеративная модель (диффузия/CFM) при одной реализации
на условие есть **сглаживатель по условиям**: её закон в новом x —
взвешенная смесь обучающих реализаций соседних условий. Разброс — ширина
окна сглаживания, которое сжимается по мере обучения. Если условие содержит
идентификатор (фон, маска наблюдений, дата), соседей нет — и модель
коллапсирует к точечной массе; «калибровка» при этом невозможна никаким
objective. Явный свежий шум на условии задаёт ширину окна (полосу) явно
и делает модель постериором для *зашумлённой* задачи — с ценой в резкости.

**Что показано.**
- Теория: Т1 (точечная масса при уникальном условии, любой strictly proper
  objective), Т2 (шум σ на условии ⇒ population-минимизатор CFM = смесь
  Надарая–Ватсона Σ w_i δ_{y_i} = точный постериор при эмпирическом прайоре;
  следствия: состоятельность при N→∞, σ→0, Nσ^d→∞; фиксированный шум не
  помогает; смешивание только вдоль зашумлённых координат — незашумлённая
  маска/фон остаются идентификаторами), Т3 (копула смеси близка к истинной
  до коллапса; не переживает коллапс сети — контрпример ревью принят).
  **П2** («сеть без явного шума — сглаживатель с полосой h(T), сжимающейся
  с обучением») — **гипотеза**, не доказана.
- Синтетика с известным постериором (16-мерная гетероскедастичная гауссова,
  MLP-CFM): (а) калибровка определяется плотностью условий, не числом
  реализаций на условие (при бюджете N·k: k не важно; N = 512 — коллапс,
  N = 8192 — калибровано); (б) шум = полоса: калибровка при σ ≳ d_NN, при
  σ = .3 ES модели = ES истинного постериора зашумлённой задачи (.90),
  RMSE .23 → .37; фиксированный шум не помогает; (в) «три закона» (ревью §3):
  истинный постериор P*, эмпирическая смесь-цель Т2, точная CFM-ODE смеси,
  сеть — интегратор точен; при σ = .3 сеть ≈ цель ≈ истина; при σ = .1 цель
  почти точечная (N_eff 1.4–1.8), а **сеть лучше своей цели** (spread
  .61–.90, ES ближе к P*): у сети есть собственное сглаживание сверх σ;
  (г) копула смеси ≈ истинная (corr .94–1.00) при сохранённом разбросе.
- MNIST учитель–ученик (процедурный учитель с точно сэмплируемым
  постериором: класс, поворот, масштаб): N = 500/2000/8000 → spread/true
  .38/.85/.92; уникальный 8-битный ключ в условии → .29 (коллапс); ключ +
  свежий шум σ = .5/1.0 → .64/.82; 8 реализаций на ключ → .95.
- Лёд, диагноз: NN-расстояние между условиями / масштаб аномалии — медиана
  .47 (соседей на масштабе аномалии нет); CFM с фоном: spread/RMSE .68 → .43
  по эпохам (коллапс); регуляризованная версия (balanced) — константный
  разброс, s/r .90, но ранги неплоские, атомы (ровно 0 и cap) неверные.
- Лёд, причинные вмешательства: **arm D** (та же архитектура, фон убран,
  только треки + белый шум .05) — коллапса нет (s/r .86, у треков 1.00),
  цена RMSE .156 → .171; **arm C** (field-dropout под протокол siconc-only)
  лучше базового (RMSE .181 vs .190, CRPS .056 vs .062). В очереди: arm R
  (UNet-MSE, те же каналы — «нужна ли генеративность»), arm F (tracks-only
  с библиотечной геометрией для всех сэмплов — «маска как идентификатор»).
- Метод (OOF-перекалибровка, слой v19): генератор — регрессор + источник
  структуры зависимостей; маргиналы строятся заново по невязкам на *чужих*
  датах: kriging-апдейт среднего с точным соблюдением наблюдений (nugget по
  LOO на невязках дня d) → OOF-квантили по ячейкам (расстояние до трека ×
  среднее) в латенте с атомами (0 и cap как пороговые события) → копула:
  √½·стандартизованная аномалия генератора + √½·стационарное поле → PIT
  внутри даты (KS пулированная ≈ 0). Гарантия: авто-калибровка относительно
  σ-алгебры ячеек (conformal-типа).
- Лёд, dev-2022 (cross-fit 5×8, purge ±1): fair CRPS .0415 → .0337 (−19 %,
  39/40 дат), RMSE .156 → .136, s/r .99, per-date rank-TV .157 → .084,
  атом нуля .41 → .53 (истина .54), ES −17 %, блочный CRPS 16px −27 %,
  cross-score по двум независимым банкам .0331 (ревью §4: выигрыш не
  артефакт зависимости членов).
- Абляции (ревью §5): только апдейт среднего (kriging + obs) даёт CRPS
  .0352 = 76 % выигрыша; перекалибровка разброса — ранги .129 → .08;
  копула генератора vs стационарная/чужой даты — CRPS .0340 vs .0352/.0351,
  ES только у смеси (слабо). Baseline'ы с той же настройкой на training-
  фолдах вокруг сырого среднего: EMOS .0413, ECC-Q .0408, split-conformal
  .0564 vs слой .0335 (−19 % к лучшему baseline'у). Без генератора
  (фон + kriging + OOF + стационарная копула): .050 vs .034.
- **Test-2023 (единственный прогон, 200 дней, siconc-only, 5 членов).**
  arm C сырой: RMSE .275 → .203 (относительно как на dev), но IIEE кромки

  месяцам максимум выигрыша в сезон таяния (июнь CRPS .100 → .040,
  RMSE .294 → .172), где сам генератор был хуже всего.

## 1. Моя честная оценка (для ML-конференции)

Сильное: причинная цепочка (синтетика → MNIST → лёд) для одного механизма;
феномен «сеть лучше своей цели»; запечатанный test с переносом слоя без
перенастройки.

Слабое, что напишут рецензенты: (1) Т1–Т3 — известные инструменты
(Scarvelis 2023 closed-form diffusion; Kamb–Ganguli 2024; Biroli 2024;
аугментация условия — Ho 2022); новое только П2, а оно не доказано.
(2) Один физический домен, OSSE, датасет незнакомый, числа 3D-Var коллег
ещё не вставлены. (3) Слой — классическая постобработка (kriging + ECC +
quantile mapping) с ML-новизной близкой к нулю; версия слоя выбиралась
на тех же 40 датах (оптимизм отбора задекларирован). (4) arm C на test
хуже legacy по кромке. (5) arm R / arm F ещё не посчитаны.
Оценка: main-track NeurIPS/ICML ~10–15 %, workshop 70–80 %, JAMES/GMD
60–70 %.

## 2. Что я предлагаю сделать с теорией (главный вопрос к ревью)

**Теорема (неявная полоса), набросок.** CFM-сеть в ленивом (NTK/kernel)
режиме, градиентный поток до времени T. Тогда поле скорости v_T — kernel
ridge регрессия целевых скоростей с λ ≈ 1/T (early stopping ↔ ridge;
Yao–Rosasco–Caponnetto 2007); по оси условия x это ядерный сглаживатель
с эффективной полосой h(T) ↓ 0. По оценкам устойчивости потока (Benton et
al. 2023; Грёнуолл при липшицевом поле) закон сэмплов сети при времени T
близок в W₂ к NW-смеси Т2 с h_eff² ≈ σ² + h(T)². Следствия: σ = 0, T → ∞
⇒ δ_{y_i} (Т1); σ > 0 ⇒ пол σ (Т2); конечное T ⇒ сеть глаже цели —
объяснение «трёх законов». Проверяемое предсказание: h(T), измеренная по
сети, должна воспроизводить кривую коллапса по эпохам (синтетика, MNIST).
Известные риски: ленивый режим; ядро сглаживает и по y_t, надо выделить
x-компоненту; константы у t → 1.

Дополнительно: количественная версия Т2 (смещение O(σ), дисперсия
O(1/(Nσ^d)) ⇒ критерий σ ≳ N^{−1/d} явно).

## 3. Что такое «метод» в одну строку

(i) Критерий: сравни σ (шум/аугментация на условии) с d_NN условий в
метрике сети; при идентификаторе в условии и σ ≪ d_NN разброс = полоса, не
постериор. (ii) Починить в модели: свежий шум на идентифицирующих
координатах с σ по критерию (цена — резкость) или убрать идентификатор.
(iii) Если нельзя — OOF-перекалибровка (слой): генератор как регрессор +
структура, маргиналы заново по невязкам на чужих условиях, гарантия
относительно σ-алгебры ячеек.

2. Теорема о неявной полосе + измерение h(T) на синтетике/MNIST (1–2 нед).
3. Второй физический домен: 2-D турбулентность с управляемой плотностью
