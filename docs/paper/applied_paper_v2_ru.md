# [Прикладной текст, черновик v2 по решению ревью-5] Условная CFM-модель как предиктор анализа концентрации морского льда + OOF-перекалибровка ансамбля: честная оценка на протоколе 3D-Var

*Черновик Methods / Results / Limitations. Числа — dev-2022 (40 дат, native, cross-fit 5×8) и test-2023 (200 дней, siconc-only; просмотренный benchmark, не holdout). Все расчёты завершены; NOT_AVAILABLE отмечено явно. Ничего из этого текста не является причинной валидацией ML-механизма ключа.*

## Methods

**Задача и данные.** Анализ SIC (и толщины в native-протоколе) на день d на области 320×256 (водная маска 48 637 пикселей) из фона (поле M2M той же календарной даты годом раньше) и OSSE-наблюдений: значения M2M в час 23 на реальных SRAL-footprint'ах дней d, d−1, d−2 (rule-1, приоритет новейшего). Обучение 2016–2021, dev 2022, test 2023 (200 дней подряд, протокол коллег `main_200d`). Паспорт наблюдений (T8): при deployment-политике ~83 % наблюдаемых пикселей — открытая вода (NaN модели → 0), ~330 пикселей — лёд; при обучении реальная ветка исключает NaN-пиксели (флаг по умолчанию), синтетическая ветка прямых треков (50 % сэмплов у A/C/D/R) их не фильтрует, библиотечная ветка (F) — почти не содержит (8 из 559 в аудированных батчах). Эта несогласованность обучение/оценка — общее ограничение всех плеч и фиксируется как часть протокола.

**Модели.** 50M UNet, conditional flow matching (concat-conditioning), dopri5; плечи: legacy balanced (обучение с валидацией на 2023 — используется только фиксированный ema_last), чистые переобучения A (native), C (field-dropout толщины, для siconc-only), D (только треки), F (только треки, библиотечная геометрия), R (UNet-MSE, детерминированный, те же каналы/бюджет).

**Постобработка (слой v19, заморожен).** Латент с атомами (0 и cap как пороговые события); kriging-апдейт среднего по невязкам треков с nugget по LOO дня d и точным соблюдением наблюдений дня d; OOF-маргиналы по ячейкам (расстояние до трека × среднее) на training-фолдах; зависимость — смесь стандартизованных аномалий генератора и стационарного поля (λ = ½), внутридатная эмпирическая PIT. Кандидат-альтернатива по итогам P6.2: те же маргиналы + стационарная зависимость (обе спецификации заморожены; выбор — по единой таблице, не задним числом).

**Оценка.** Детерминированные показатели (RMSE/MAE/IIEE(.15) среднего) по нашему скореру на наших масках для всех методов, включая 3D-Var коллег (их код запущен нами без изменений в отдельной копии; фон совпал с нашим до нуля; единый набор наблюдений с hash `c1bced…` — совпадает побайтно). Вероятностные показатели — с явным объектом оценки: ordinary CRPS объявленного M-членного ансамбля; U-формула — только для условно-iid сырых членов; cross-score двух условно независимых 5-членных запусков — закон случайного члена 5-членной процедуры (lineage в `ice_cross_score_lineage.md`). Fair/U для постобработанных зависимых членов не называется несмещённой оценкой закона.

## Results

**R1. Условное среднее (dev-2022, native, 40 дат).** RMSE фона .256; среднее CFM: legacy .156, arm A .166; UNet-MSE arm R .227 (ema_best по dev — .208, оптимистично). При одинаковой постобработке (v9-тип, стационарная зависимость, fold-fitted закон) RMSE после апдейта: фон → —, UNet-MSE .171, CFM arm A .142, CFM legacy .140; ordinary CRPS 10-членного ансамбля (единая таблица, одни даты/маски): .0546 / .0500 / .0396 / .0386 (U-формула: .0497 / .0456 / .0361 / .0352). Утверждение: данный CFM-предиктор среднего лучше данного UNet-MSE при одинаковой постобработке; необходимость генеративного *ансамбля* — NOT_TESTED.

**R2. Слой v19 (dev-2022, native).** Объекты оценки: ordinary CRPS 10-членного слоёного ансамбля .0372; U-формула .0337 (оптимистичность не гарантирована, знак смещения не фиксирован); cross_Q5 .0331; raw_U .0415 ≈ raw_cross .0413. Единая таблица: ordinary CRPS raw .0451 → v19 .0375 (−17 %, 39/40 дат); только апдейт среднего .0383. Ранги: per-date TV .157 → .084; атом нуля .41 → .53 (истина .54); cap .022 → .095 (истина .060 — перебор, известное ограничение).

**R3. Разложение выигрыша (последовательная абляция, не причинные доли).** Блок обновления по наблюдениям без перекалибровки маргиналов (общий физический сдвиг членов к kriged-среднему — попарные разности инвариантны, ratio 1.000 — затем клиппинг к [0, cap], затрагивающий ~60 % водных пикселей (нули открытой воды), и точное соблюдение наблюдений дня d на 1.3 % пикселей; после клиппинга spread .141 → .126): ordinary .0383 / U .0352 (89 % разности raw→v19 по CRPS набирается этим блоком; v19 добавляет .0008 при RMSE +3 %; на test-2023 v19 даёт сверх блока MAE −.006 и IIEE −.036); классические baseline'ы вокруг сырого среднего: EMOS .0413, ECC-Q .0408, split-conformal .0564. **P6.2 (копула при буквально одинаковых маргиналах, assert на мультимножества и маргинальный CRPS):** устойчивого преимущества условной зависимости генератора не обнаружено — на масштабах < 16 px стационарное поле лучше (ES16 .684 vs .689; вариограмма lag 1 .0070 vs .0078), на ≥ 16 px генератор даёт 1–3 % и не отличим от аномалий чужой даты (среднее по области: чужая дата лучше).

**R5. Tracks-only и геометрия (dev-2022).** Arm D (фон скрыт): RMSE .171, s/r .90; у треков s/r 1.00. Матрица D/F × реальная/библиотечная геометрия × deployment/train-matched политика (T9): различие D/F зависит от политики наблюдений; на реальной геометрии при train-matched политике разрыв полного RMSE существенно уменьшается (+.023 → +.002), но сохраняется в MIZ (+.061 → +.075) и на фиксированном удалённом регионе (референс — маски D/real/deployment: +.10 → +.06); переход к train-matched ухудшает абсолютный RMSE обеих моделей (D .171 → .213, F .194 → .215); на библиотечной геометрии картина иная (при train-matched F .166 < D .189). Эксперимент не изолирует причинную роль геометрии-идентификатора. Относительный дефицит spread у F сохраняется во всех режимах (s/r .46–.59 против .75–.88 у D). Ошибка обеих моделей сосредоточена в MIZ и на кромке (RMSE .28–.43). C7 («маска как идентификатор») — CONFOUNDED / NOT_IDENTIFIED: вмешательство одновременно меняет информативность наблюдений.

## Limitations

OSSE (значения модели на реальной геометрии), один регион, dev — 40 дат одного года, test — 200 дней одного года (просмотренный benchmark); несогласованность политик открытой воды обучение/оценка для всех плеч; отбор версий слоя v3→v15 на тех же 40 датах (оптимизм отбора; v16–v19 — без отбора по score); U-CRPS для постобработанных ансамблей — не несмещённая оценка; cross_Q5 — не закон 10-членной процедуры; cap-атом перебирается; условная копула генератора без устойчивого преимущества; сравнение с 3D-Var — только детерминированное (вероятностной версии 3D-Var нет); стоимость 10 траекторий CFM против одного прохода UNet-MSE не учтена; числа RUNNING-строк отсутствуют до завершения.
