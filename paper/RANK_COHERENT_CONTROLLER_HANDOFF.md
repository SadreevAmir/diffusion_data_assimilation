## Exact invocation

```sh
RANK_COHERENT_SOURCE_JSON=/sealed/source.json \
RANK_COHERENT_OUTPUT_DIR=/server/result \
python3 paper/rank_coherent_runner_prototype.py \
  --source-experiment joint_full_condition_validation_2022
```

`--source-experiment` is the sole scientific/runtime contract parameter. The two
environment values are controller-resolved server-local I/O locations. Unknown
CLI arguments fail closed. The runner uses the standard library only and makes
no network or accelerator calls.

## Sealed source JSON

The top-level keys are exact: `schema_version`, `source_experiment`,
`dataset_split`, `start_date`, `end_date`, `case_stride`, `artifact_policy`,
`raw_ensemble`, `truth`, `spatial_weights`, `truth_rank_tie_uniforms`, and
`frozen_thresholds`. The schema is `rank-coherent-prototype-v1`. Arrays must
contain the frozen 40 cases and ten members, share one finite rectangular shape,
and concentrations must lie in `[0,1]`. `truth_rank_tie_uniforms` must be the 40
values generated by the existing sealed tie-seed implementation; the prototype
does not create a competing seed contract.

`frozen_thresholds` has exactly four keys:
`boundary_mass_absolute_tolerance`,
`member_semivariogram_absolute_tolerance`, `rank_l1_absolute_maximum`, and
`coverage_absolute_error_maximum`. These values must be copied from reviewed
controller policy and sealed with the source. They are not selectable arguments.

## Exact compact outputs

The output directory contains exactly `run_status.json`,
`aggregate_case_mean_metrics.json`, `per_case_metrics.csv`, and `metadata.json`.
It contains no raw member, truth, candidate, or anomaly arrays. The per-case CSV
has one raw and one candidate metric row for each case.

## Mandatory trusted-integration replacement

The prototype executes the leakage-safe folds, forecast-only analog selection,
complete-field rank pairing, training-only alpha choice, capped-simplex
projection, diagnostics, and compact serialization. It deliberately sets
`gate_inputs.operational.trusted_full_gate_integrated=false`,
`metadata.decision_bearing=false`, and therefore `overall_eligible=false`.

Before registration, the controller review must replace only the prototype gate
adapter and interval sensitivity with its unchanged full no-compensation gate
and frozen paired bootstrap implementation. Construction, folds, purge, analog
ties, alpha set and selection, projection, CLI, compact filenames, and source
schema must remain unchanged. A parity fixture must verify the complete compact
handoff with `validate_compact_handoff`; until then this prototype cannot support
an experiment proposal or scientific claim.

The exact replacement boundary and executable directory-level parity oracle are
frozen in `paper/RANK_COHERENT_ADAPTER_SPEC.md` and
`paper/rank_coherent_adapter_parity.py`. The trusted synthetic dry run must pass
`validate_result_directory(path, decision_bearing=True)`; the local prototype
must pass the same oracle with `decision_bearing=False`.

The controller-visible admission record is also executable rather than
narrative-only: `validate_admission_record` in `rank_coherent_reference.py`
requires the exact field set, a literal non-placeholder reviewed mode, lowercase
40/64-hex identities, non-empty test command and sentinel,
`decision_bearing_validation=PASS`, and an empty deviations list. It returns
only the reviewed mode that a proposal may copy literally.

Validate the explicit controller-visible JSON file without copying fields by


Success prints exactly `reviewed_mode=<literal reviewed mode>`. Invalid JSON,
