# Rank-coherent trusted adapter: frozen replacement boundary

Status: PARITY_FIXTURE_READY_NO_IMPLEMENTED_MODE

The candidate construction is immutable. A trusted integration may replace
exactly two prototype components: (1) `gate_inputs`, `gate`, and diagnostics
needed by the unchanged full no-compensation gate; and (2) the date and fixed
non-overlapping four-case-block interval implementation. It must not change the
source schema, folds, purge, features, analog selection or ties, truth-rank ties,
complete-field pairing, alpha set or selection, bounded-simplex projection,
per-case metric definitions, filenames, or summary-only policy.

The adapter constructs every candidate and all per-case metrics first. It then
calls the controller-owned paired bootstrap on those same ordered case deltas
and the controller-owned full gate on those same candidate/raw records. Missing
criteria, exceptions, non-finite output, or schema mismatch fail the run.

Before registration, the trusted synthetic dry run must pass
`validate_result_directory(path, decision_bearing=True)` from
`rank_coherent_adapter_parity.py`. The local fixture command is:

```sh
python3 -m unittest -v paper/test_rank_coherent_adapter_parity.py
```

The oracle enforces exact files, frozen envelope, complete structural handoff,
reconciliation of all 80 CSV rows with aggregate means, status/gate identity,
and the declared decision-bearing role. Local prototype parity proves adapter
compatibility only; it does not register a mode or establish a scientific result.
